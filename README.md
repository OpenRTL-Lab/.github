# OpenRTL — MIT-Licensed Digital Hardware

**From algorithms to RTL: high-performance, reliable digital hardware for commercial applications.**

[Official website](https://openrtl.top/) ·
[GitHub organization](https://github.com/OpenRTL-Lab) ·
[Organization profile](profile/README.md)

This repository contains OpenRTL's public organization profile, with a separate
Markdown file for each language. Explore released Chisel/SystemVerilog hardware,
reproducible verification evidence, and custom ASIC/FPGA development services
on the [organization homepage](https://github.com/OpenRTL-Lab).

Our focus is original MIT-licensed digital hardware, including compute
accelerators, controllers and interfaces, with commercial-grade performance
and reliability as engineering goals. Project documentation defines the
verified configurations, measured results and integration limits.

[ZK accelerator catalogue](https://github.com/OpenRTL-Lab/zk-accelerators/blob/main/README.en.md) ·
